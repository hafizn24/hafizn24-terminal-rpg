# CODEBASE_OVERVIEW.md — Read this first (AI agent context)

> Token-efficient map of this repo. Check this file before reading source files.
> Project: `hafizn24-terminal-rpg` v0.1.0 — terminal-themed browser roguelite RPG.
> Flow: Title → ClassSelect → Town hub → 5x5 procedural Dungeon → turn-based Combat → descend/boss, checkpoint saves to localStorage.
> UI rule: minimal + single-purpose screens. No character art (text-only). Logs are single-line (latest only, fixed height, never expand).

## 1. Snapshot
- Stack: React 18.3.1 + Zustand 4.5.5 + Vite 5.4.2 + Tailwind 3.4.10 + TS 5.5.4 + Vitest 2 + ESLint 9 + vite-plugin-pwa. Font: JetBrains Mono.
- Entry: `index.html` (#root) → `src/main.tsx` → `src/App.tsx` (`TerminalWindow > ErrorBoundary > ScreenRouter + StatusBar`; StatusBar hidden on title/classSelect/gameOver/ending) → `src/components/screens/ScreenRouter.tsx` (maps `currentScreen` → screen).
- Screens (`src/types/game.ts: Screen`): `title | classSelect | town | dungeon | combat | inventory | stats | gameOver | shop | questBoard | meta | bestiary | relicDraft | ending`.
- Scripts: `npm run dev` (localhost:3000/5173), `npm run typecheck` (`tsc --noEmit`), `npm run lint` (`eslint src`), `npm run build` (`tsc -b && vite build` → `dist/` + PWA `sw.js`/`manifest`), `npm run preview`, `npm test` (`vitest run` — engine + 1,000-run balance + save + telemetry). CI (`.github/workflows/ci.yml`) runs typecheck+lint+test+build; Pages (`.github/workflows/pages.yml`) deploys `dist/` (relative `base: './'`). README.md at root.

## 3. Core models (`src/types/game.ts`)
- `Player { name, class: warrior|mage|rogue|cleric, level, exp/expToNext, stats: Stats, gold, inventory: InventorySlot[], equipment: {weapon,armor,accessory}, floor, statPoints }` (unspent level-up points for STR/DEX/INT/HP/MP)
- `Stats { str,dex,int,hp,maxHp,mp,maxMp,def }` (`StatType` += `def`), `Item { id,name,type: weapon|armor|potion|key|misc, rarity, price, statBonus?, healAmount?, mpRestoreAmount?, effect?: bomb|smoke, effectPower?, cleanse? }` (Purifying Herb; dungeon_key opens vaults). Basic attack scales class primary stat (warrior STR, rogue DEX, mage/cleric INT); Guard = halve + 15% dodge, no MP. `ClassSkill { id,name,mpCost,power,unlockLevel,1/4/8,kind: strike|nuke|healStrike|rage|shield|weaken|critNext|evade|cleanse }` — 3/class in `ClassDefinition.skills`. `Enemy { minFloor, maxFloor?, onDeath?: burst }`. `FloorModifier none|golden|cursed|swarm`. `Player.relics: string[]`. `MetaState.endlessUnlocked`.
- `Enemy { attack,defense,expReward,goldReward,lootTable: LootEntry[], skills: EnemySkill[] (burn|poison), isElite? }`
- `Room { type: empty|monster|treasure|trap|shop|stairs|boss|elite|shrine|start, explored, x,y, enemy?, item?, trapDamage?, shopItems? }`, `DungeonState { floor, rooms: Room[][], playerPos, gridSize:5 }`
- `Quest { type: daily|side, objective: {type: kill|floor|gold|collect, target, required}, progress, reward: {gold,exp,itemId?}, completed }`
- `GameStats { bestFloor, bossesKilled, runsStarted }`, `RunStats` (live telemetry) / `RunSummary` (frozen at death + shards), `MetaState { shards, upgrades, kills }` (separate key, survives newGame), `DailyEntry { name,classId,floor,bosses,ts }`, `LogMessage { type: info|combat|loot|danger|system }`

## 4. State stores
- `src/game/store/gameStore.ts` (`create<GameStore>`, `ShopType=blacksmith|potion_shop|magic_shop`, `ShopReturn=town|dungeon`, `StatsReturn=town|inventory|dungeon`):
  State: `currentScreen='title', player, dungeon, quests, gameOverMessage, hasSave, selectedShop, shopReturn, statsReturn, lastSave, stats, runSeed (null=legacy), dailyKey, run: RunStats|null, lastSummary: RunSummary|null`.
  Saves persist the full active `dungeon` map + `runSeed`/`dailyKey` (no regen on re-entry; flee keeps map). Inn costs `15×level` escalating per rest-without-descend.
  Actions: `setScreen, setSelectedShop(shop,ret?), setStatsReturn(ret), createPlayer(name,classId)` (runSeed = daily seed or random; applies Renown bonuses; gold 50 + 3x `hp_potion_s`, save immediately), `updatePlayer, setDungeon, setQuests, setGameOver` (awards shards `floor+10×bosses`, freezes `lastSummary`, records daily entry), `save(), load()` (→ dungeon or town; backfills `statPoints`/`def`), `newGame()` / `startDaily(dateKey)` (clear → classSelect), `checkSave(), updateQuestProgress(event,target)` (floor/gold=max, else increment), `addItem(id,qty)`, `gainExp()` / `allocateStatPoint(stat)` (delegate to `engine/rules/progression.ts`), `recordRunKill/Damage/Floor()` (telemetry).
- `src/game/store/metaStore.ts`: `shards, upgrades, kills, earnShards, buyUpgrade, recordKill, recordDaily/getDailyBoard`. `refresh()` on screen mount. Meta survives `newGame` (own key).
- `src/game/store/uiStore.ts`: `logMessages (last 50), nextLogId, addLog(text,type), clearLogs()`.

## 5. Data + systems
- `game/data/classes.ts`: 3 skills/class (Lv1/4/8) — warrior Power Strike/Rage(+50% atk 3t)/Stone Skin(ward 30+5Lv), mage Fireball/Weaken(-35% foe atk 3t)/Pyroblast 4.2x, rogue Backstab/Cheap Shot(auto-crit)/Smoke Veil(dodge 2), cleric Holy Light 2.2x+heal/Cleanse(+INT heal)/Divine Shield(ward 20+2INT). Combat buffs (`playerBuffs`, `enemyWeaken`) tick on enemy turns; shown as status tags.
- `game/data/enemies.ts`: `ENEMIES[16]` tier-windowed (`minFloor/maxFloor` — slime 1-6 … demon_knight 20+, variants: armored/volatile slime, brute orc, swift wolf, hex priest, iron golem; volatile `onDeath.burst` can kill back), `BOSS_ENEMIES[6]` exact-tier spine (5 goblin_king, 10 necromancer, 15 flame_tyrant, 20 dragon_lord, 25 void_reaver, 30 demon_king; endless rotates the last three). ASCII renders ONLY in `BestiaryScreen`.
- `game/data/ascii.ts`: live helpers `isBossEnemy()`, `getFloorTheme()` (boss=red, f7+=yellow, f4+=green, else cyan). `ELITE_CROWN_ART` / `BOSS_AURA_TOP/BOTTOM` are retired, data-only, unused by render.
- `game/data/items.ts`: ~26 items in `ITEMS`, `SHOP_STOCK { blacksmith[9], potion_shop[6], magic_shop[7] }`. Sell = 0.5x floor.
- `game/systems/dungeonGenerator.ts`: `FINAL_FLOOR=30`, `gridSizeForFloor` 5/6/7 (1-10/11-20/21+), `CHECKPOINT_INTERVAL=5`, `isBossFloor`, `SHOP_SPAWN_CHANCE=0.3`, `SHOP_PITY_FLOORS=3`. `generateDungeon(floor, rng?)`: start/stairs/boss-guard; weights 3 monster/2 treasure/1 trap/2 empty, 12% elite if floor≥2, traps capped 2/floor, maze walls (BFS-verified, 30 attempts then open fallback), 1x shrine (not on cursed), 0-1x shop (pity unseeded only), 1x vault floor 3+ (key-gated rare+ loot), treasure 12% key, golden +1 treasure / swarm +2 monsters, modifier roll (none 60/golden 15/cursed 12/swarm 13). Exact-tier bosses via `getBossForFloor`; tier-windowed `getEnemiesForFloor`. Stairs boss-gated + sealed at 30 pre-ending. Flee keeps map. Traps dodgeable (`trapDexForFloor=8+floor`, Ward Charm halves). Entry reveals adjacents. Helpers: `scaleEnemy (*1+(floor-1)*0.15, elite HP1.5/ATK1.3/reward2x)`, `getRandomLoot`, `getVaultLoot`, `trapDamage=5-15+floor*2`, `allReachable()` (tested), `getAdjacentRooms()`.
- `game/data/relics.ts` (`RELICS[8]`: blood_vial/feather/whetstone/ward/focus/lucky/iron_hide/adrenaline) + `engine/rules/relics.ts` (`getRelicMods`, `effectiveSkillCost`, `unlockedSkills` — pure). Boss victory → `relicDraft` (pick 1 of 3, veteran 100g fallback); floor-30 boss → `completeEnding()` → `ending` screen (credits + summary + endless unlock) → `continueEndless()` (floor 31+). Sim ignores relics/vault keys (documented floor).
- `engine/`: `rng.ts` (`Rng`, `mulberry32`, `seedFromString`, `randomSeed`, `todayKey`, `getDailySeed(ForKey)`, `rngForFloor`, `rngInt/Chance/Pick/Shuffle/Float`); `rules/damage.ts` (primary-stat attack, skill scaling, DEF total, variance/crit/dodge math, trap rating, intent preview — CombatScreen/DungeonScreen delegate here); `rules/progression.ts` (`planLevelUps`, `applyStatPointToStats`, point constants — gameStore delegates here); `rules/relics.ts` (mods, costs, unlocks); `sim/autoplay.ts` (headless opener-only policy sim: volatile burst, swarm exp, sealed vaults) + `sim/balance.test.ts` (22 tests incl. 1,000-run band: all-class median 5, trap share 10-14%).
- `game/data/meta.ts`: `META_UPGRADES` (vigor/wealth/talent/prepared + costs), `shardsForRun`. `utils/metaStorage.ts` (`terminal_rpg_meta`, `terminal_rpg_daily:YYYY-MM-DD`).
- `game/systems/questSystem.ts`: `QUEST_TEMPLATES[13]` (variant hunts incl. armored/volatile/golem; no dupes), `generateDailyQuests(date)`→3, `generateSideQuests(floor)`→2 depth-filtered (kill targets surfaced, floor goals ≤ floor+3), `checkQuestProgress/isQuestComplete/checkDailyReset()`. Objective union is kill|floor|gold (dead `collect` removed).
- `utils/rng.ts`: `randomInt, chance, pickRandom, shuffleArray, calcDamage(atk,def)=max(1,atk-def*0.5)*0.85-1.15, calcCritChance(dex)=min(0.4,0.05+dex*0.01), calcDodgeChance(pDex,eDex,guard)=min(0.3,max(0,0.05+(pDex-eDex)*0.01+(guard?0.15:0))), calcExpForLevel(l)=50*l^1.5, getRarityColor()`.
- `utils/storage.ts` (`terminal_rpg_save`, `SAVE_VERSION=2`): `saveGame/loadGame/hasSaveData/deleteSave()`, `DEFAULT_STATS {1,0,0}`. Id-based slots/equipment resolved via `ITEMS` on load (`instanceData` reserved for enchants); `migrate()` dispatcher chains 0→1→2 (statPoints/def backfill, object→id conversion, relics/modifier backfill); FNV hash is tamper-evident (warn + load, solo game). gameStore.load trusts it — one copy of every backfill. Keys: `terminal_rpg_meta`, `terminal_rpg_daily:*`, `terminal_rpg_telemetry` (opt-in), `terminal_rpg_muted`, `terminal_rpg_daily_reset`.
- `utils/audio.ts`: synth SFX (`playSfx`, 13 scores, lazy AudioContext, never throws) + `isMuted/setMuted`; `SoundToggle` on Title/Town; wired to combat/dungeon/shop/rest/relic events. `utils/telemetry.ts`: opt-in local events (runStarted/runEnded/bossKilled), `classifyDeath`, summary aggregates, JSON export; UI in Renown ("Field reports").
- `components/ErrorBoundary.tsx`: crash panel (save untouched) wrapping the router. PWA: `vite-plugin-pwa` (autoUpdate, precached shell, `public/icon.svg`); Google Fonts online-only with monospace fallback.

## 6. Screens (what edits where)
- `ScreenRouter.tsx`: `screenMap` 14 entries. Add new screen here + `Screen` union + store `setScreen`.
- `TitleScreen`: ASCII art, `checkSave()` on mount, New (confirm if save) → `newGame()`, Continue → `load()`, Daily Challenge → `startDaily(today)` → classSelect (shared daily seed), Renown/Bestiary shortcuts, today's local leaderboard (top 5). Shows bestFloor/bosses.
- `ClassSelectScreen`: cards + name input (max16, Enter) → `createPlayer`.
- `TownScreen` (minimal, vertically centered): `Enter Dungeon` primary full-width (+ daily badge when `dailyKey`), 2x3 `Inn (cost)/Stats/Quests/Inventory/Renown/Bestiary` (`Stats (N)` badge when points available), `Shops — resupply here` panel with Blacksmith/Potion Shop/Magic Shop + one-line hints. No embedded stats, one-line `Floor · Best · Bosses · checkpoint · saved` status.
- `StatsScreen`: dedicated stats tab. Only place `StatAllocationPanel` appears full-page. `statsReturn` controls Back target (town/inventory/dungeon).
- `DungeonScreen` (minimal): header `FLOOR label + [Flee]`, map panel (no legend/tips/counter), compact D-pad (`^<v>`), Descend button only on stairs, single-line `LogPanel`. Boss floors tint red via `getFloorTheme()`.
- `CombatScreen` (minimal, text-only, no art): mirrored panels — enemy (`HP` bar + intent line) and `You` (`HP` + `MP` bars + skill/status line), same `Panel` format. Actions grid ABOVE the single-line latest-only log (fixed `h-7`, truncate, never expands). `ProgressBar` renders filled `█` in bright color + empty `░` in dim (never bright-on-bright) with `whitespace-nowrap` so bars can't wrap/bleed against scanlines.
- `ShopScreen`: header `[S] Blacksmith` / `[P] Potion Shop` / `[M] Magic Shop`, Buy/Sell tabs, back to `shopReturn` (`[Back to Dungeon]` / `[Back to Town]`). Sell: `getSellPrice`=0.5x floor, equipped items blocked (must unequip; `[E]`/EQUIPPED badge + disabled button), `isValuableItem` (rare/epic or ≥150g sell) needs two-step inline confirm, per-stack Sell All + bulk-sell `misc` loot with total + confirm. `InventoryScreen`: tabs all/gear/potions/misc/stats — `stats` tab renders `StatAllocationPanel` (dedicated tab), other tabs show one-line equipment summary + minimal item rows (name + qty + Use/Equip/Drop). `QuestBoardScreen`: header `Guild Board`, Active/Available tabs, text-only progress (`Progress: n/m`, no block bar), daily reset key `terminal_rpg_daily_reset`, accept/claim (gold+exp+item, remove, save). `GameOverScreen`: box-art banner + summary panel + Run Summary panel (floors/kills/bosses/damage/biggest/gold/shards, daily flag) + `Load Last Save` (if save) / `New Game` / `Title Screen`. `MetaScreen` (Renown): shard balance + 4 upgrades with rank/cost buttons. `BestiaryScreen`: foes/bosses tabs, unlock-on-kill entries with ASCII + stat card, `???` when locked.

## 7. UI/terminal primitives
- `TerminalWindow({title,children})`: title-bar dots + scanlines overlay. `StatusBar`: compact two-row footer (name/LV/class + gold/floor/XP, then 10-char HP/MP bars, truncate only, never scrolls). `LogPanel`: minimal single-line latest-only (`h-7`, truncate, `[x]` clear, no filters/expand/scroll). `StatAllocationPanel`: STR/DEX/INT/HP/MP/DEF rows with [+] when `statPoints>0`, ATK (primary-stat + gear) / DEF (base + gear) / CRIT preview (used only in StatsScreen + Inventory stats tab). `Button({variant: primary|danger|ghost, size: sm|md|lg, glow})`, `Panel({title, titleAlign})`, `ProgressBar({current,max,color,length=20})` (filled `█` bright + empty `░` dim).
- Styling: Tailwind `terminal-*` (`bg #0a0a0a, green #00ff41, cyan, red, yellow`), `font-mono`, `terminal-glow/border/btn`, `animate-fade-in/shake/...`, `prefers-reduced-motion` off. Tap ≥44px.
- `hooks/useKeyboard(keyMap)`: keydown, lowercase, preventDefault, skips inputs.

## 8. Persistence + conventions for AI agents
- Keys: `terminal_rpg_save` (run: player/dungeon/quests/runSeed/dailyKey), `terminal_rpg_meta` (shards/upgrades/kills — survives newGame), `terminal_rpg_daily:YYYY-MM-DD` (local leaderboard), `terminal_rpg_daily_reset`, (`terminal_rpg_quests` legacy). Autosaves: createPlayer, inn rest, shop buy/sell, stat allocate, victory, descend, quest claim, flee — `dungeon` always persisted (cached run, no regen). Debug: `JSON.parse(localStorage.getItem('terminal_rpg_save'))`; reset: remove save+quests+reset then reload.
- Game loop: `title --New/Daily--> classSelect --create--> town <--> dungeon <--> combat --victory--> dungeon --E--> floor+1 (boss-gated on 5/10/15) --flee--> town (map cached)`; `town<-->shop|inventory|stats|questBoard|meta|bestiary`; `inventory stats-tab <--> StatAllocationPanel`; death→gameOver (shards + summary + daily entry)→load/new/title.
- AI rules: single source of truth = `types/game.ts` + `gameStore` (+ `metaStore` for cross-run state); combat/progression math lives in `engine/rules/` (pure, tested) — UI delegates, never duplicates; `utils/rng.ts` keeps the legacy Math.random globals; seeded paths take an explicit `Rng` from `engine/rng.ts`; dungeon layout only in `dungeonGenerator.ts`; quests only via `updateQuestProgress('kill'|'floor'|'gold')`; saves change via `storage.migrate()` (bump `SAVE_VERSION`); audio via `playSfx` (never throw, respect mute); telemetry is opt-in local only; theme via `tailwind.config.js` + `terminal-*` classes, never hardcode hex; run `npm run typecheck` + `npm run lint` + `npm test` before PR (CI enforces); keep rooms one-shot (clear to `empty` after loot/trap/shrine). Enemy ASCII renders ONLY in `BestiaryScreen` — do not re-add `<pre>` art to CombatScreen. Only text banners remain: `TitleScreen` logo, `GameOverScreen`/`EndingScreen` boxes.
- Common tasks: new item → `items.ts` + `SHOP_STOCK` if sellable; new enemy → `enemies.ts` (tune `getEnemiesForFloor`); new screen → `types/game.ts` + `ScreenRouter` + `App.tsx` StatusBar rule; new quest → `QUEST_TEMPLATES`.
